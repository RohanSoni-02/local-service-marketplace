# Local Service Marketplace - Feature List

## Overview
This is a local service marketplace mobile web app that connects users with verified local service providers (shops) for home services, repairs, and tool rentals. The app features real-time service broadcasting, offer negotiation, group booking for societies, and end-to-end transaction management.

---

## Core User Features

### 1. Service Discovery & Search
- **Text Search**: Search for parts, tools, or services by description (e.g., "15mm pipe joint", "MCB switch")
- **Photo Search**: Scan or upload photos to identify parts/tools (preview feature)
- **Category Browsing**: Browse services by 8 main categories:
  - Plumber
  - Electrician
  - Carpenter
  - AC Repair
  - Hardware
  - Tool Rental
  - Painter
  - Appliance
- **Nearby Shops**: View shops within 5km radius in list or map view
- **Sorting**: Shops sorted by rating (highest first) in category views
- **Distance Display**: Shows distance to each shop in kilometers
- **Service Radius**: Displays how far each shop travels for services

### 2. Shop Profile & Verification
- **Shop Gallery**: Photo gallery showcasing shop and work
- **Verification System**: Three-tier verification:
  - Gold Verified (highest)
  - Verified (standard)
  - New (newly joined)
- **Rating System**: Star rating based on customer reviews
- **Experience Metrics**: Jobs completed counter
- **Operational Info**: Business hours and service area
- **Shop Bio**: Detailed description of shop specialties
- **Location Services**: Map integration showing exact shop locations

### 3. Service Booking Workflow
- **Issue Selection**: Choose from category-specific issue types
- **Problem Description**: Detailed text description of the problem
- **Media Attachment**: Optional photo upload to illustrate issue
- **Service Timing**:
  - Instant service (as soon as possible)
  - Scheduled service (predefined time slots)
- **Budget Management** (Optional):
  - Set expected budget range (e.g., "₹300-500")
  - Allow/disallow shop negotiation
- **Real-time Broadcasting**:
  - Request sent to 4 nearby shops simultaneously
  - Live radar visualization showing broadcast range
- **Offer Management**:
  - Receive multiple offers from different shops
  - View offered prices and ETAs
  - Counter-offer negotiation system
  - Track negotiation status (pending, countered, accepted, declined)
- **Offer Acceptance**:
  - Accept offer to proceed with service
  - Automatic tracking initiation upon acceptance
- **Job Tracking**:
  - Status timeline: Broadcasting → Accepted → On the way → Completed
  - Real-time status updates with descriptions
  - Technician assignment visibility
  - Estimated arrival times
- **Post-Service**:
  - Secure in-app chat with service provider
  - Payment confirmation (via UPI in demo)
  - Rating and review submission
  - Service cost breakdown

### 4. Tool Rental Workflow
- **Tool Discovery**: Browse available tools at verified shops
- **Tool Details**:
  - Name, category, and condition (Excellent/Good/Fair)
  - Daily rental price clearly displayed
  - Refundable deposit amount
- **Rental Configuration**:
  - Select rental duration (1-14 days)
  - Instant cost calculation: (daily price × days) + deposit
  - UPI payment integration (demo)
- **Rental Management**:
  - Pickup confirmation process
  - Active rental tracking with pickup/due timestamps
  - Deposit held until return verification
  - Return process to reclaim deposit
  - In-app chat with shop during rental period

### 5. User Account & History
- **Bookings Tab**:
  - Complete booking history with status indicators
  - Shop details and service information
  - Completed job costs and user ratings
  - Direct chat access from booking history
  - Cancelled booking visibility
- **Rentals Tab**:
  - Rental history with active/returned status
  - Tool details and rental periods
  - Pickup and return timestamps
  - Total rental costs displayed
  - Direct access to shop chat
- **Chats Tab**:
  - Conversation list with all service providers
  - Last message preview for each thread
  - Visual indicators for verified shops
  - Direct access to full conversation threads
- **Chat Interface**:
  - Real-time messaging (simulated with auto-replies in demo)
  - Message timestamps
  - User vs. shop message styling
  - Shop contact information (call button)
  - Message input with send functionality

### 6. Profile & Settings
- **Personal Information**: Name, phone number, and address display
- **Account Management**:
  - Saved addresses management
  - Payment methods (UPI-focused in demo)
  - Notification preferences
  - Language selection (English default)
- **Support & Legal**:
  - Verified shops policy information
  - Help center access
  - Terms & privacy policy
  - Help & support resources
- **Account Actions**: Secure logout functionality
- **App Info**: Version number display (Thikana v1.0.0)

### 7. Society / Group Booking System
- **Society Linking**:
  - Users can link their account to apartment society/building
  - Society registration flow for new communities
  - Admin designation for society creators
  - Society verification and management
- **Group Requests**:
  - Residents can create group service requests for:
    - Pest control
    - Water tank cleaning
    - Gardening/maintenance
    - Other society-wide services
  - Detailed request description and preferred date
  - Tracking of participating flats
  - Status management: open → closed → completed
- **Shop Participation**:
  - Service providers submit offers for group requests
  - Per-flat pricing model with minimum flat requirements
  - Offer comparison and selection by society admins
  - Offer negotiation and counter-offer capabilities
  - Final offer selection and request closing
- **Society-Specific Views**:
  - Admin dashboard for managing society requests
  - Resident view for joining and tracking requests
  - Search functionality to find societies by name/pincode
  - Registration flow for new societies

## Technical Architecture

### Frontend Framework
- **Next.js 16.3.0**: App Router with React 18
- **TypeScript**: End-to-end type safety
- **Tailwind CSS v4**: Utility-first styling with custom design system
- **Turbopack**: Next.js compiler for fast development
- **Shadcn/ui**: Accessible UI primitives (buttons, cards, dialogs, tabs, etc.)
- **Lucide Icons**: Consistent icon set throughout the application

### State Management & Data Flow
- **React Hooks**: useState, useEffect, useRef for local state
- **SearchParams**: URL-based state sharing and deep linking
- **Suspense Boundaries**: For client-side rendering boundaries
- **Dynamic Imports**: Code splitting for non-critical components
- **Client-Only Components**: Where browser APIs are required (maps, etc.)
- **Mock Data Layer**: Local data simulation for development/demo

### API & Communication
- **Next.js Navigation**: Client-side routing with useRouter/useSearchParams
- **REST-style Endpoints**: Simulated through mock-data.ts functions
- **Real-time Features**: Streaming updates via client state (broadcast simulation)
- **WebSocket-Ready**: Architecture supports real-time features
- **Error Boundaries**: Graceful error handling and fallback UI
- **Loading States**: Skeleton loaders and placeholder content

### Performance & Optimization
- **Code Splitting**: Route-based and dynamic import splitting
- **Image Optimization**: Next.js Image component with automatic sizing
- **Asset Optimization**: Optimized fonts and icons
- **Bundle Analysis**: Conscious dependency management
- **Caching Strategy**: Client-side caching for instant navigation
- **Prefetching**: Intelligent link prefetching for navigation

### Deployment & DevOps
- **Vercel Optimized**: Configured for Vercel deployment platform
- **Environment Variables**: Secure configuration management
- **Build Optimization**: Production-ready build process
- **Type Checking**: Strict TypeScript configuration
- **Linting**: ESLint integration for code quality
- **Responsive Design**: Mobile-first approach with adaptive layouts

## Data Models & Entities

### Core Entities
- **Shop**: Service provider with verification, ratings, location, hours
- **Category**: Service classification with icons and names
- **Tool**: Rentable item with condition, pricing, and availability
- **Booking**: Service request with issue, timing, status, and offers
- **Rental**: Tool rental agreement with duration, pricing, and timeline
- **Review**: Customer feedback with rating and text
- **Society**: Apartment building/complex for group booking
- **GroupRequest**: Society-initiated service request for multiple flats
- **Offer**: Shop response to group request with pricing and terms
- **ChatMessage**: Communication between user and shop

### Status Flows
- **Booking Status**: broadcasting → accepted → on_the_way → completed
- **Rental Status**: active → returned
- **Group Request Status**: open → closed → completed
- **Offer Status**: pending → countered → accepted → declined (from user perspective)
- **Chat Sender**: user or shop

### Business Logic
- **Service Radius**: Shops service within defined kilometers
- **Verification Tiers**: Based on job completion and quality metrics
- **Pricing Models**:
  - Services: Negotiated or fixed pricing
  - Rentals: Daily rate + refundable deposit
  - Societies: Per-flat pricing with minimums
- **Matching**: Proximity-based (within 5km) for individual services
- **Group Buying**: Volume-based pricing for society requests
